Meduza 0.2 draft contract fixtures
=================================

Hand-authored language-design examples, not outputs of a RESOLVE compiler.
All catalog names, identity hashes and policy references are fixtures, not
installed capabilities or grants. Files must never be sent to a real executor.

fetch obtains an observation; query returns non-authoritative data; ensure checks
it; achieve requests bounded resolution of a goal; conditional branches explicitly
suspend on unknown/conflicting evidence; set snapshots a supplied collection;
creation makes a typed set; method references a proposed public method interface.
All completed calls still require objective verification before a success claim.

The JSON schema checks structure only. Symbol resolution, typechecking, effect
checking, provenance, dependency hashes and execution behavior require the future
compiler/runtime. See docs/meduza-v2-design.rst for the intended semantics.
