READ owns interpretation

Source → parsing and structural relations → grounded roles → interpretation audit → acceptance gate → distillation → RESOLVE.

Unresolved meaning stays with READ and triggers ASK. RESOLVE receives structured points, original wording and evidence. Distillation calls no generative model.

Meaning and acceptance are separate

Supported interpretation means the bounded rules account for the input and required references. Acceptance additionally requires calibration. A lack of calibration does not mean the user wrote an ambiguous sentence.

What changed

  • Explicit tense, aspect, voice and polarity per point.
  • Bindings belong to a frame and role; confirmed ledger claims can name a source hash and role.
  • Unrepresented words block readiness even when full-source evidence retains them.
  • Unknown text is retained; garbage/noise annotations cannot override meaning checks.
