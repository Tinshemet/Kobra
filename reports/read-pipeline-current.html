The current READ pipeline

Code assigns supported roles. An optional model proposes unresolved interpretations. An external gate decides ACCEPT or ASK, while preserving context evidence.

Experimental, opt-in path. This is the implemented GatedRuleReader flow, not a fully connected production assistant. No held-out confidence calibration is installed, so current uncalibrated routes go to ASK. The active library, archive and automatic ASK dialogue are not implemented.

What the context ledger holds
The source ledger preserves the current sentence. The new context ledger records what was supplied from earlier turns. Keeping either does not prove that its content is true.
Retained evidence
  • Turn IDs, speaker roles, exact text and hashes.
  • Supplied WORLD entities, plus literal mention spans in prior turns.
  • Optional caller claims with exact source quotations.
  • Explicit correction links preserve the earlier claim instead of deleting it.
Not automatic memory
  • No extraction of facts from every previous turn.
  • No automatic trust in an assistant's earlier assertion.
  • No database, archive retrieval or active-library promotion.
  • The caller must supply or persist the context between calls.


Illustrative context record (abbreviated)
{
  "previous_turns": [
    {"id": "u1", "role": "user", "content": "Use the blue box."},
    {"id": "u2", "role": "user", "content": "Correction: use the red box."}
  ],
  "world_entities": [
    {"id": "blue-box", "record": {"name": "blue box"}},
    {"id": "red-box", "record": {"name": "red box"}}
  ],
  "claims": []
}
Both statements and entities survive. This record alone does not infer which box a new pronoun means. Claims remain empty unless the caller explicitly supplies source-backed claims.


Serpent's independent side
Before Kobra sees a case, Serpent annotates required context, possible resolving channels, structural ambiguity and the context actually provided. Multi-turn fixtures include prior turns and entity mention evidence. Standalone cases explicitly record an empty context snapshot.
The default policy keeps all cases. Optional filters act before selection, retain exclusions and report denominators. Teacher-side ambiguity/reference answers are not inference hints. The sentence-only batch runner still sends only ID and text; a complete live multi-turn benchmark adapter is not yet connected.

How correctness is measured
The evaluator separates correct code, correct AI and correct ASK. Wrong accepted interpretations, unnecessary ASK, and ASK for an unrelated reason are distinct failures. Grounding IDs are checked against reference answers as well as literal slots.
The earlier 293/300 (97.67%) result was a reused-data routing simulation: 280 code-correct cases plus 13 correct saved model answers. It did not evaluate this calibrated gate, automatic memory, or a live multi-turn system. The model-first fresh batch result was 260/300 (86.67%) under a bounded slot contract.
